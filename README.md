# TangoDots

**TangoDots | 毎日続く英単語帳**

FSRS（Free Spaced Repetition Scheduler）を使い、英単語を少量ずつ継続して学ぶための無料Webアプリです。

公開サイト: https://tangodots.yato-lab.com/

## できること

- 新規単語は初期設定で1日50語。10〜100語を5語刻みで変更可能
- 期限が来た復習を新規単語より優先して出題
- 「もう一度 / 難しい / 良い / かんたん」の4段階で回答
- 回答履歴に応じてFSRSが次回の復習タイミングを調整
- 直近91日分の学習記録をドットで表示
- PCとスマートフォンのブラウザで利用可能

## 評価の目安

| 評価 | 選ぶとき |
| --- | --- |
| もう一度 | 思い出せなかった、または間違えた |
| 難しい | 思い出せたが、かなり迷った・自信がなかった |
| 良い | 無理なく思い出せた。迷ったらこれ |
| かんたん | すぐに、自信をもって思い出せた |

固定された復習間隔とは異なり、FSRSは各単語への回答履歴を使って復習時期を調整します。覚えている単語への不要な反復を減らし、忘れやすい単語に時間を使いやすくすることを目指しています。

詳しい使い方は、公開サイトの [使い方ページ](https://tangodots.yato-lab.com/about) を参照してください。

## データと料金

- 広告・課金・サブスクリプションはありません。
- ブラウザには、学習履歴を識別する匿名端末IDのみを保存します。
- 学習履歴・FSRSの復習予定・1日の単語数は、JSONファイルとして書き出し／復元できます。ブラウザのデータを削除する前に、iCloud DriveやGoogle Driveなどへバックアップしてください。
- 初期デッキには2,300語を収録しています。

## 匿名の利用統計

サービス改善のため、Cloudflare Workers Analytics Engine と Google Analytics 4 で匿名の集計を行います。Google Analytics ではページ閲覧・滞在時間などの利用状況のみを計測し、IPアドレスの匿名化、Googleシグナル・広告パーソナライズの無効化を設定しています。Cloudflare側ではホーム・学習画面の開始数、4種類の評価の選択数、単語数設定の変更、バックアップ操作、任意で送信された年代区分だけを集計します。単語・訳語・カードID・端末識別子・IPアドレス・メールアドレス・正確な年齢は分析データに含めません。運営向けの確認方法は [docs/analytics.md](docs/analytics.md) を参照してください。

## 開発

```bash
npm install
npm run dev
```

Cloudflareへの公開:

```bash
npm run deploy
```

単語・訳語を公開配信する場合は、参照した辞書などの利用条件・権利を確認してください。
