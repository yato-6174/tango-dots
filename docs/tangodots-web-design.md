# TangoDots Webアプリ設計書

- 文書バージョン: 1.0
- 対象: PC・スマートフォンのモダンブラウザ
- 公開基盤: Cloudflare Workers

## 目的

TangoDotsは、英単語をFSRSで復習するWebアプリである。初期デッキはユーザー提供の `単語データ.xlsx` を変換した2,300語の単語・日本語訳リストを使用する。インストール不要で、スマートフォン・PCのブラウザから学習できる。

## 主要機能

- 表面の英単語を表示し、操作で日本語訳を表示する。
- 日本語の4評価「もう一度 / 難しい / 良い / かんたん」で回答する。
- FSRS v6により次の復習日時と記憶状態を計算する。
- 期限切れの復習を優先して出題し、未学習カードを続けて出題する。
- 直近91日の回答数を4段階の継続ドットで表示する。
- 学習履歴とカード状態をブラウザのローカルストレージに保存する。

## UI

画面は単一ページとし、上から「今日の枚数」「継続ドット」「単語カード」の順に表示する。余白・文字・4つの明示的な評価ボタンを主役にし、広告、外部リンク、常時表示の複雑なナビゲーションは置かない。

| 表示 | 条件 |
| --- | --- |
| 薄いグレーのドット | 回答なし |
| 薄い緑のドット | 1〜9枚 |
| 中間の緑のドット | 10〜29枚 |
| 濃い緑のドット | 30枚以上 |

## FSRS

公式のTypeScript実装 `ts-fsrs` 5.4.1を使用する。初期設定は目標保持率90%、短期学習ステップは1分・10分、再学習ステップは10分とする。各回答でFSRSのカード状態と次回日時を更新し、画面上には各評価を選んだ場合の予定間隔を表示する。

## データ・プライバシー

`public/vocabulary.json` は連番、英単語、日本語訳で構成する。初期版にはアカウント・サーバーDB・解析SDKを導入しない。カード状態とレビュー履歴はローカルストレージだけに保存するため、同じブラウザ内でのみ維持され、端末間同期は行わない。

## 公開・運用

Cloudflare Workers互換のビルドをCloudflareへデプロイする。独自ドメインはCloudflareアカウントでDNS設定後に接続する。公開前に、単語・訳語の作成に参照した辞書などの利用条件を確認する。将来アカウント同期を追加する場合は、認証、削除・エクスポート、プライバシーポリシーを別途実装する。

## 受入条件

- 英単語を開いて4評価のいずれかを選ぶと、次回日時がFSRSで更新される。
- ページを再読込みしてもカード状態・学習履歴・継続ドットが保持される。
- スマートフォン幅でもカードと評価ボタンが操作できる。
- 2,300語の初期デッキを読み込める。
- `npm run build` とレンダリングテストが成功する。
